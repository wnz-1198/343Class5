# DjangoBlog 演示环境初始化说明

本仓库已包含前端构建产物，不需要再执行 npm 构建。

## 1. 安装 Python 依赖

```powershell
cd "src\DjangoBlog-master"
python -m pip install -r requirements.txt
```

建议使用 Python 3.10 及以上版本和独立虚拟环境。

## 2. 初始化演示数据

```powershell
powershell -ExecutionPolicy Bypass -File "scripts\setup-demo.ps1"
```

脚本会：

1. 使用 SQLite 创建测试数据库；
2. 执行全部数据库迁移；
3. 创建演示账号、5 篇文章、分类、标签和评论。

## 3. 启动系统

```powershell
$env:DJANGO_USE_SQLITE = "True"
python manage.py runserver
```

浏览器打开：http://127.0.0.1:8000/

## 4. 演示账号

| 角色 | 用户名 | 密码 |
|---|---|---|
| 超级管理员 | demo_admin | demo123456 |
| 普通用户 | demo_reader | demo123456 |

登录地址：http://127.0.0.1:8000/login/

## 5. 演示路线

1. 首页：近期文章、热门文章、评论和标签；
2. 打开「DjangoBlog 系统优化实践」文章；
3. 点击「导出 Markdown」验证原文下载；
4. 使用 `demo_reader` 登录并发表评论；
5. 打开 `/health/` 查看数据库和缓存健康状态；
6. 在后台审核评论、查看文章浏览量变化。

## 6. 重置演示环境

删除 `src\DjangoBlog-master\db.sqlite3`，重新执行 `scripts\setup-demo.ps1` 即可。

## 7. 使用 MySQL 时

不设置 `DJANGO_USE_SQLITE`，改为配置以下环境变量：

```text
DJANGO_MYSQL_NAME
DJANGO_MYSQL_USER
DJANGO_MYSQL_PASSWORD
DJANGO_MYSQL_HOST
DJANGO_MYSQL_PORT
```
