| 项目 | 说明 |
|---|---|
| 用例名称 | 发布文章 |
| 主要参与者 | 已登录的超级管理员 |
| 目标 | 让普通文章处于已发布状态，并进入前台列表的查询范围 |
| 触发条件 | 管理员在后台新增文章并保存为已发布，或把已有草稿改为已发布 |
| 前置条件 | 管理员已通过后台权限检查，且可选择已存在的分类和超级管理员作者。依据：`djangoblog/admin_site.py:25–26,39–46`、`blog/admin.py:100–114`、`blog/models.py:145–163` |
| 成功后置条件 | 文章保存为 `status='p'`，普通文章 `type='a'` 满足首页查询条件；实际出现在哪一页取决于排序、分页和缓存。依据：`blog/models.py:126–139,176–194`、`blog/views.py:80–94,119–138` |
| 失败后置条件 | 表单校验失败时，本次提交不保存为已发布，管理员可修正后重新提交。依据：`blog/admin.py:22–27,61–67,118–119` |

## 基本流程：新增并发布普通文章

| 步骤 | 管理员操作 | 系统响应 |
|---|---|---|
| 1 | 登录后进入后台文章管理，选择新增 | 后台按超级管理员身份检查访问权限，文章管理页使用 `ArticlelAdmin` 及其模型表单。 |
| 2 | 填写标题和 Markdown 正文，确认发布时间，选定作者及分类。可选填标签、排序权重、目录和评论设置 | 表单通过作者和分类 ID 控件选取关联记录，作者范围限定为超级管理员，标签可为空。 |
| 3 | 确认类型为普通文章、状态为已发布，提交表单 | 表单校验字段及标题唯一性，通过后保存文章，发布状态为 `p`。 |
| 4 | 在后台列表检查发布状态，或打开文章查看页面 | 后台列表显示状态，可通过“在站点上查看”进入详情。首页查询会纳入已发布的普通文章，并按置顶权重、发布时间排序。 |

依据：`djangoblog/urls.py:60–65`、`djangoblog/admin_site.py:25–26,39–46`、`blog/admin.py:22–27,61–125`、`blog/models.py:119–195`、`blog/views.py:119–138`。

## 备选流程

| 分支 | 操作与结果 | 源码依据 |
|---|---|---|
| A1 单篇草稿转发布 | 打开已有草稿，将状态改为已发布后保存。文章主键沿用原记录。 | `blog/admin.py:61–98,118–119`、`blog/models.py:99–103,126–131` |
| A2 批量发布 | 在后台列表勾选文章并执行“发布所选文章”。动作对选中记录直接执行 `update(status='p')`，保留其类型和发布时间。 | `blog/admin.py:33–34,53–56,94–98` |
| A3 先保存草稿 | 在表单中选草稿再保存。状态为 `d`，首页查询不会选入，之后可走 A1 或 A2。 | `blog/models.py:99–103,126–131`、`blog/views.py:130–135` |
| A4 发布独立页面 | 表单中选择独立页面并发布。已发布独立页面进入导航上下文的查询范围，首页仍只选普通文章。 | `blog/models.py:109–139`、`blog/context_processors.py:19–41`、`blog/views.py:130–135` |

## 异常与业务规则

| 条件 | 系统行为 | 源码依据 |
|---|---|---|
| 未以超级管理员身份访问后台 | 后台权限检查不通过。 | `djangoblog/admin_site.py:25–26` |
| 标题重复，或缺少必填信息 | 文章模型表单校验失败。标题最长 200 字符且全站唯一，作者、分类和发布时间必填。 | `blog/admin.py:22–27`、`blog/models.py:119–125,145–163` |
| 已发布但首页暂时未见 | 普通保存的信号处理会清除部分查询缓存键，包括首页首屏。批量发布直接更新状态，绕过这条保存信号路径。判断发布是否成功时可先检查后台状态。 | `blog/admin.py:33–34,118–119`、`djangoblog/blog_signals.py:67–75,118–152` |

## 验收场景

- 新增普通文章并保存为已发布，后台状态为已发布，文章满足首页列表条件。检查首页时按实际排序、分页和缓存查找。
- 新建草稿后从后台执行发布，确认同一条记录的状态从 `d` 改为 `p`，类型与发布时间保持原值。
- 用已有文章的标题新增文章，确认表单拒绝重复标题，后台没有新增同标题记录。
- 发布独立页面，确认它符合导航查询条件，且不会出现在首页普通文章列表中。

以上为依据现有源码编写的验收场景。
