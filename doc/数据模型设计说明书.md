## 1. 概述

### 1.1 项目背景

DjangoBlog 是一款基于 Python 3.10+ 和 Django 5.2 构建的高性能博客平台。本系统提供文章发布、评论互动、分类标签管理、第三方登录等核心博客功能，并通过插件系统支持浏览计数、SEO 优化、文章推荐等扩展能力。

### 1.2 设计目标

- 支持多用户（作者）独立发布文章
- 支持文章多级分类、多标签标注
- 支持嵌套评论（无限层级回复）与 Emoji 反应
- 支持第三方 OAuth 登录（微信、QQ、GitHub、Google 等）
- 支持可配置的站点级系统参数
- 数据模型具备高查询性能（合理的索引设计）

### 1.3 技术选型

| 类别 | 技术 |
|------|------|
| ORM 框架 | Django ORM (Django 5.2) |
| 数据库引擎 | MySQL 8.x / SQLite (开发) |
| 字符集 | utf8mb4 (支持 Emoji) |
| 缓存 | Redis / LocalMem |

## 7. 数据一致性与完整性约束

| 约束类型 | 约束说明 | 实现方式 |
|----------|----------|----------|
| **主键约束** | 所有表均有自增主键 | Django AutoField / BigAutoField |
| **外键约束** | 10 对关联关系全部 CASCADE 删除 | `on_delete=models.CASCADE` |
| **唯一约束** | 用户名、邮箱、文章标题、分类名、标签名、友情链接名称/顺序、侧边栏顺序、OAuth 平台类型 | `unique=True` |
| **复合唯一** | 同一用户对同一评论的同一种反应唯一 | `unique_together` |
| **业务约束** | BlogSettings 只能有 1 条 | `Model.clean()` 校验 |
| **枚举约束** | status、comment_status、type、reaction_type、color_scheme 等均限制取值 | `choices` |
| **非空约束** | 业务必填字段 NOT NULL | `null=False, blank=False` |
