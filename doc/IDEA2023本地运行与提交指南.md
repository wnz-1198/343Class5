# IDEA 2023 本地运行与 Git 提交指南

## 1. 打开项目

需要区分两个目录：

| 目录 | 用途 |
|---|---|
| `D:\ruan gong da zuo ye\343Class5` | Git 仓库根目录，包含 `src` 和 `doc` |
| `D:\ruan gong da zuo ye\343Class5\src\DjangoBlog-master` | Django 工程目录，包含 `manage.py` |

推荐在 IDEA 2023 中打开仓库根目录，然后在 Project Structure 中把 `src/DjangoBlog-master` 标记为项目源码。

## 2. Python 解释器

Django 5.2 需要 Python 3.10 或更高版本。

1. 打开 `File → Project Structure → Project`；
2. 选择 Python 3.10、3.11 或 3.12；
3. 如使用虚拟环境，创建 `.venv`；
4. 打开终端，在 `src\DjangoBlog-master` 下执行：

```powershell
python -m pip install -r requirements.txt
```

## 3. MySQL 配置

### 3.1 创建数据库

```sql
CREATE DATABASE djangoblog
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

### 3.2 IDEA 运行配置

打开 `Run → Edit Configurations`，新建 Python 配置：

- Script：`src\DjangoBlog-master\manage.py`
- Parameters：`runserver`
- Working directory：`src\DjangoBlog-master`

在 Environment variables 中填写：

```text
DJANGO_MYSQL_NAME=djangoblog
DJANGO_MYSQL_USER=root
DJANGO_MYSQL_PASSWORD=你的MySQL密码
DJANGO_MYSQL_HOST=127.0.0.1
DJANGO_MYSQL_PORT=3306
```

不要把真实密码提交到 Git。

## 4. SQLite 快速演示

临时测试可不启动 MySQL：

```text
DJANGO_USE_SQLITE=True
```

然后执行：

```powershell
cd "D:\ruan gong da zuo ye\343Class5\src\DjangoBlog-master"
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver 127.0.0.1:8000
```

SQLite 文件会被 `.gitignore` 排除，不提交到仓库。

## 6. Git 分支

孙金龙成员分支：

```text
sjl_branch
```

查看状态：

```powershell
cd "D:\ruan gong da zuo ye\343Class5"
git status
git branch --show-current
git remote -v
```

切换到成员分支：

```powershell
git fetch origin
git switch sjl_branch
git pull --ff-only origin sjl_branch
```

## 7. 提交本次作业

```powershell
git add doc src
git commit -m "feat: 完成第9-10周系统优化、测试与维护文档"
git push origin sjl_branch
```

如果已有多个周次提交，可分批推送：

```powershell
git log --oneline --decorate -10
git push -u origin sjl_branch
```

## 8. IDEA Git 图形界面操作

1. 打开 `Git` 工具窗口；
2. 在 Local Changes 中检查文件，排除日志、数据库和虚拟环境；
3. 右键选择 `Commit Directory`；
4. 填写提交信息；
5. 选择 `Commit and Push`；
6. 确认远端为 `origin/sjl_branch`；
7. 推送后在 GitHub 页面确认提交和文件存在。

## 9. 常见问题

| 问题 | 处理 |
|---|---|
| `No module named django` | 当前解释器不是 Python 3.10+ 或依赖未安装 |
| 无法连接 MySQL | 检查 MySQL80 服务、端口、用户名和密码 |
| `mysqlclient` 安装失败 | Windows 使用与 Python 对应的 wheel，或在 IDEA 终端安装 |
| 数据库无表 | 执行 `python manage.py migrate` |
| 页面无样式 | 检查静态文件和 Vite/前端资源 |
| 推送提示分支落后 | 先 `git pull --ff-only origin sjl_branch`，解决冲突后再推送 |
| 中文乱码 | 文件保存为 UTF-8，控制台使用 UTF-8 |
