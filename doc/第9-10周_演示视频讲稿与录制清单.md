# DjangoBlog 第 9—10 周演示视频讲稿与录制清单

> 建议时长：6—8 分钟
> 视频格式：MP4
> 片头必须显示：小组编号、全部小组成员姓名
> 放映项目：DjangoBlog 优化版

## 1. 录制前准备

1. 启动 MySQL 80 服务。
2. 在 IDEA 2023 中打开 `src/DjangoBlog-master`。
3. 选择 Python 3.10+ 解释器并安装 `requirements.txt`。
4. 在运行配置中设置数据库环境变量。
5. 执行 `python manage.py migrate`。
6. 创建管理员和演示数据。
7. 准备一个普通用户、一篇已发布文章、一篇草稿和至少两条评论。
8. 浏览器使用 100% 缩放，关闭私人通知。
9. 录制 1920×1080 或更高分辨率，麦克风先录音测试。

## 3. 讲稿

### 00:00—00:30 片头

“大家好，我们是软件工程 5 班第[编号]小组。我们的项目是 DjangoBlog 博客系统。本项目完成了内容建模、评论区、第三方登录、插件扩展和系统优化。下面由我演示第 9—10 周的维护成果。”

### 00:30—01:20 项目启动与架构

“项目使用 Django 5.2 和 MySQL 8。当前通过 IDEA 2023 启动开发服务器。系统按 blog、accounts、comments、oauth、servermanager 和 djangoblog 拆分。公共布局由 templates 继承，文章列表使用查询预加载，评论使用树形自关联。”

演示：

- 打开项目结构；
- 展示 `settings.py` 的 SQLite/MySQL 开关；
- 启动服务；
- 打开首页。

### 01:20—02:20 浏览与搜索

“首页只展示已发布文章。分类页、标签页和作者页复用文章列表组件。打开一篇文章后，可以看到 Markdown 正文、目录、标签、评论和相邻文章。”

演示：

- 点击首页文章；
- 使用分类或标签；
- 进行搜索；
- 展示文章详情。

### 02:20—03:10 新增：Markdown 导出

“本次新增文章 Markdown 导出。导出入口位于文章标签区域右侧。匿名用户可以下载已发布文章，草稿只有作者或超级管理员可以下载。文件名兼容中文标题。”

演示：

- 点击“导出 Markdown”；
- 打开下载文件；
- 展示标题、元数据和正文；
- 返回并使用草稿地址验证无权限时返回 404。

### 03:10—04:00 评论与审核

“登录用户可以发表评论和 Emoji 反应。评论是否直接显示由站点配置决定，管理员可以在后台审核。评论写入后会清理文章、侧栏和 SEO 缓存，并触发邮件通知。”

演示：

- 登录普通用户；
- 发表评论；
- 添加 Emoji；
- 切换管理员审核；
- 返回前台查看结果。

### 04:00—04:50 优化：浏览量原子更新

“原实现先读取浏览量再加一，在并发访问时可能丢失更新。优化后使用数据库的 `F` 表达式原子自增。即使两个旧对象同时访问，最终数据库也会增加两次。”

演示：

- 展示 `blog/models.py` 的 `viewed()`；
- 运行新增测试 `blog.test_view_count`；
- 说明断言为最终浏览量 2。

### 04:50—05:40 优化：健康检查

“健康检查不再只返回固定状态。新接口执行数据库 `SELECT 1`，并写入、读取缓存探针。全部正常返回 200，任一关键依赖异常返回 503。”

演示：

- 访问 `/health/`；
- 展示 JSON；
- 可选：暂停 MySQL 后刷新，展示 503，再启动 MySQL。

> 如本机数据库停止操作不方便，可只展示自动化失败用例，不要伪造运行结果。

### 05:40—06:30 测试与质量

“本次新增 8 个自动化测试方法，分别覆盖浏览量、导出权限、中文文件名和健康检查。项目全部 Python 文件完成语法编译检查，156 个文件、0 个语法错误。个人负责的 oauth 模块增加了 43 条 SJL 注释，并修复了外部请求超时和日志泄露风险。”

演示：

- 展示测试文件；
- 运行测试命令；
- 展示测试通过结果；
- 展示质量报告和 Git 提交记录。

### 06:30—07:00 结尾

“本次维护在不修改数据库模型的前提下，完成了并发统计、依赖健康检查、Markdown 导出、配置安全和回归测试。所有内容已提交到 `sjl_branch` 分支。感谢老师观看。”
